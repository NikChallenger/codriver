## Improvements

- Sensitive MCP server information is now stored in Obsidian keychain.
- Provider tokens can now be edited directly in provider settings.
- Deleting a provider or MCP server requires confirmation and offers removal of the associated secret.

## Fixes

- Fixed tool schema compatibility issues with third-party MCP servers.

## Compatibility

- Secrets for existing MCP servers migrate automatically to Obsidian keychain.
