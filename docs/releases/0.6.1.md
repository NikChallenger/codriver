## Improvements

- Added optional Detailed file logging for troubleshooting, including tool arguments, results and final assistant answers. Enabling it requires confirmation because logs may contain sensitive data.

## Fixes

- Audio transcription and Voice input now respect disabled models in provider settings.
- Fixed long commands losing instructions during tool continuations. Commands above 12000 characters now offer Cancel request or Continue with the full context.
- Fixed the reference time changing during tool continuations.
- Improved read-context retention for supported read-only Direct Plugin API calls, including calls that return errors.
