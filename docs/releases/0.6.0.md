## Improvements

- Create and edit Canvas files with validated, reviewable changes and a built-in Canvas skill.
- Added OAuth 2 authentication support for HTTP MCP servers on desktop.
- Configure OpenAI-compatible providers using ready-made presets.
- Use desktop voice input to record speech and insert editable text into the chat.
- Improved PDF text extraction, preserving line breaks and releasing resources after processing.
- Control automatic active-note context and remove model-selected skills from the current session.
- Added experimental Direct API call with separate Obsidian and per-plugin permissions. Plugin methods run with the installed plugin's authority.
- Added an in-app feedback link.

## Fixes

- Provider generation failures now show a clear error and prevent tool calls from failed responses.

## Compatibility

- Editing an open Canvas currently requires Obsidian 1.14.4; unsupported editor versions block the write.
